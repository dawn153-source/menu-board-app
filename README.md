# 브릿지 커피 디지털 메뉴판

손님이 테이블의 QR을 찍으면 휴대폰으로 보게 되는 메뉴판입니다.
광주 북구 비엔날레에 있는 스페셜티 커피 가게 "브릿지 커피"를 위해 만들었습니다.

## 보는 방법

`index.html` 파일을 더블클릭하면 인터넷 창에서 열립니다.
휴대폰(가로 폭 390px 기준)에서 가장 잘 보이도록 만들었습니다.

## 화면 구성

- 맨 위: 가게 이름, 한 줄 소개, 위치
- 가운데: 메뉴 카드 (이름, 가격, 한 줄 설명)
- 맨 아래: 영업시간, 안내 문구, 전화 걸기 버튼

## 파일 설명

| 파일 | 설명 |
| --- | --- |
| `index.html` | 메뉴판 화면 (HTML, CSS, JavaScript가 한 파일에 들어 있습니다) |
| `index_우리카페예시.html` | 처음에 만든 예시 화면 (보관용) |
| `CLAUDE.md` | 이 프로젝트의 작업 규칙 |
| `자료/` | 가게 정보가 담긴 기획 시트 사진 |

## 직접 고치는 방법

`index.html`을 메모장이나 편집기로 열면 한국어 안내 글(주석)이 달려 있습니다.

- 메뉴 이름, 가격, 설명: `메뉴 고치는 곳` 부분
- 가게 이름, 소개, 영업시간: 화면 위아래의 글자 부분
- 전화번호: `tel:` 뒤의 숫자 (현재는 임시 번호 062-000-0000)
- 색: `꾸미기 설정` 부분

## 디자인

- 글래스모피즘 스타일 (반투명 카드, 부드러운 그림자, 둥근 모서리)
- 색: 짙은 갈색 `#4A3728`, 크림색 `#F5EFE6`
- 글꼴: 고운 돋움 (없으면 맑은 고딕)
